# Student Marks Analysis using Python

## About the Project
This is my first Python project. It displays student marks, calculates the average marks, and identifies the topper.

## Technologies Used
- Python

## Features
- Displays student marks
- Calculates average marks
- Finds the topper
- Displays the highest marks

## Sample Output
- Ravi: 85
- Sneha: 92
- Priya: 78
- Kiran: 88
- Average Marks: 85.75
- Topper: Sneha
- Highest Marks: 92
